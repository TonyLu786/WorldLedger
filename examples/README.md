# Examples

This directory contains reproducible integration procedures and small adapter output examples.

The first live validation fixture is [`minecraft-26.2-fixture/`](minecraft-26.2-fixture/). It defines a disposable vanilla chunk, a timed mutation sequence, an evidence record, and cross-platform digest comparison rules.

Fixtures committed here must be small, redistributable, and accompanied by enough metadata to reproduce their canonical form. Do not commit copied server regions or third-party builds merely as test data.
